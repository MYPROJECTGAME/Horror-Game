១. តើតួអង្គដែលយើងកំពុងលេងជានរណា? (The Protagonist)
ស្ថានភាពរបស់តួអង្គ៖ តួអង្គដែលយើងបញ្ជា គឺជាមនុស្សម្នាក់ដែល បានភ្ញាក់ដឹងខ្លួនឡើងទាំងវង្វេងស្មារតី មិនដឹងថាខ្លួនឯងជានរណា ឬមកដល់ទីនេះដោយរបៀបណាឡើយ (ដូចមានសរសេរក្នុងសារដើមសាច់រឿង៖ "I woke up in this place... I find a note next to me: Follow the pictures" )។
បេសកកម្មរបស់តួអង្គ៖
តួអង្គត្រូវបានគេដាក់អន្ទាក់ ឬជាប់ឃាំងនៅក្នុងទីតាំងបិទជិតដ៏គួរឱ្យរន្ធត់។
គាត់ត្រូវតែ ដើរប្រមូលផ្ទាំងគំនូរ/រូបថត (Pictures) ទាំងអស់ដែលជ្រុះរាយប៉ាយ ដើម្បីផ្គុំរកការពិតពីអ្វីដែលបានកើតឡើង និងស្វែងរកកូនសោរ/ដោះសោរទ្វារធំដើម្បី រត់គេចខ្លួនឱ្យរួចជីវិត (Escape)។
ថ្នាំភ្នែក (Eye Potions)៖ ដបថ្នាំភ្នែកដែលយើងចុច [E] មើលឃើញតាមភ្នែកខ្មោចនោះ គឺជា ញាណពិសេស (Clairvoyance) ដែលអនុញ្ញាតឱ្យតួអង្គយើងអាចតភ្ជាប់វិញ្ញាណទៅនឹងភ្នែករបស់បិសាច ដើម្បីដឹងថាបិសាចកំពុងនៅបន្ទប់ណា ហើយកំពុងដើរសំដៅមករកយើងឬអត់ ដើម្បីងាយស្រួលពួនគេចខ្លួន។


២. អត្ថន័យនៃ Map ទី១៖ មន្ទីរពេទ្យចាស់ / បន្ទប់តម្កល់សព (Morgue & Hospital)
បរិបទទីតាំង៖ ជាមន្ទីរពេទ្យចាស់ដែលត្រូវគេបោះបង់ចោលជាយូរយារណាស់មកហើយ ធ្លាប់ជាកន្លែងពិសោធន៍ខុសច្បាប់ ឬកន្លែងដែលអ្នកជំងឺបានស្លាប់យ៉ាងវេទនា និងអយុត្តិធម៌។
អត្ថន័យខ្មោច/បិសាច៖
Dead Woman៖ ជាសាកសពស្ត្រីដែលបានស្លាប់ទៅហើយ តែវិញ្ញាណមិនទៅណា បានក្រោកឡើងដើររហេតរហូតក្នុងមន្ទីរពេទ្យដើម្បីស្វែងរកមនុស្សរស់មកបំបាត់ការស្រេកឃ្លាន។
Cannibal (បិសាចស៊ីសាច់មនុស្ស)៖ ជាអតីតអ្នកជំងឺដែលរងការពិសោធន៍នៅក្នុងមន្ទីរពេទ្យនោះ រហូតប្រែក្លាយទៅជាបិសាចកាចសាហាវ ស៊ីសាកសព និងសម្លាប់មនុស្សគ្រប់គ្នាដែលហ៊ានចូលមក។
អត្ថន័យសម្រាប់តួអង្គ៖ តួអង្គយើងប្រៀបដូចជាជនរងគ្រោះ ឬអ្នកជំងឺដែលទើបតែដឹងខ្លួនឡើងវិញនៅក្នុងបន្ទប់តម្កល់សព ហើយត្រូវតែប្រញាប់រត់គេចចេញពីមន្ទីរពេទ្យខ្មោចនេះឱ្យបាន មុនពេលក្លាយជាចំណីរបស់ពួកវា។


៣. អត្ថន័យនៃ Map ទី២៖ សាលារៀនបោះបង់ចោល (Abandoned School)
បរិបទទីតាំង៖ ជាសាលារៀនចាស់ដែលត្រូវបានបិទទ្វារចោល បន្ទាប់ពីមានសោកនាដកម្ម ឬរឿងរ៉ាវអាថ៌កំបាំងដ៏រន្ធត់មួយបានកើតឡើងកាលពីអតីតកាល។
អត្ថន័យសម្រាប់តួអង្គ៖
តំណាងឱ្យការជាប់គាំងនៅក្នុងសុបិន្តអាក្រក់ ឬការចងចាំដ៏ឈឺចាប់។
រូបគំនូរ និងក្រដាសដែលតួអង្គត្រូវដើររើសនៅក្នុងថ្នាក់រៀន គឺជាតម្រុយ ឬស្នាដៃរបស់ក្មេងៗ/មនុស្សពីមុនដែលបន្សល់ទុក ដើម្បីបង្ហាញផ្លូវដល់តួអង្គឱ្យដឹងពីអាថ៌កំបាំង និងរកទ្វារចេញផុតពីអគារសាលានេះ។


សរុបជារួម៖
ហ្គេមនេះចង់បង្ហាញពី ការតស៊ូដើម្បីរស់រានមានជីវិត (Survival) របស់មនុស្សម្នាក់ដែលគ្មានអាវុធក្នុងដៃ គ្មានអ្នកជួយ មានតែការប្រើប្រាស់បញ្ញា ការសង្កេត និងការលួចពួន ដើម្បីប្រមូលតម្រុយ និងរត់គេចចេញពីកន្លែងដ៏ខ្មៅងងឹតទាំងពីរនេះឱ្យបានជោគជ័យ!
